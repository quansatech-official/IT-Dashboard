# RMMScripts

Dieses Verzeichnis enthaelt TacticalRMM-Skripte fuer die Workbench.

Der verbindliche Output-Standard fuer Audit-Notes steht in:

- `../rmm-scripts/README.md`

Neue Audit-Skripte sollen `[QT-AUDIT]` plus JSON gemaess diesem Standard ausgeben, damit der Import in `RMM Audits` sie direkt verarbeiten kann.
